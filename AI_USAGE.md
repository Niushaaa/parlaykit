# AI usage disclosure

ETHGlobal asks teams to document where and how AI tools were used. This is our account.

## Tool

**Claude (Anthropic), Opus 5.5**, used as an agentic coding assistant inside the Claude app. It wrote files, ran Foundry and Node tests, and drove a headless Chrome to test the extension.

## How we directed it

The product idea, scope and key decisions came from the team. Our original prompt (verbatim):

> I want to build a parlay builder as a browser extension for current prediction markets. so user would open say polymarket or prediction market on 1inch and the extension pops up offering to combine bets user can see on that prediction market. we calculate the price of the parlay using ParlayMarket paper mechanism (that can be simplified and use a simple product of prices for the v1 mvp) and offer the parlay backed by a vault that is open for liquidity provision. design the full product v1 mvp.

From that prompt, these design choices were made during the session. The team should review each one and edit this list to show who decided what:

- product-of-asks pricing with a per-leg house edge, with the ParlayMarket pairwise model as the v2 hook
- signed EIP-712 quotes plus on-chain re-pricing, instead of trusting client prices
- settlement by reading the Conditional Tokens payout vector, with early settlement on any losing leg and correct 50/50 handling
- ERC-4626 vault with pendingPremium/lockedPayout accounting and withdrawal caps
- one leg per event as the v1 correlation guard
- parlay positions as transferable ERC-721 tickets
